# 🌐 Language Translation Tool

A simple and interactive Language Translation Tool developed using Python.

## 📌 Project Description

This project is a Python-based translation application that allows users to translate text between multiple languages.

The application provides a clean and user-friendly interface where users can enter text, select source and target languages, and view the translated result.

## ✨ Features

- 🌍 Multiple Language Support
- 📝 Text Input
- 🔄 Swap Source and Target Languages
- 🔤 Source Language Selection
- 🎯 Target Language Selection
- 🌐 Automatic Translation
- 📋 Copy Translated Result
- 🧹 Clear Input and Output
- 🔢 Character Counter
- ⌨️ Ctrl + Enter Translation Shortcut
- ⚠️ Error Handling
- 🎨 Professional Dark Theme

## 🛠️ Technologies Used

- Python
- Tkinter
- Deep Translator
- MyMemory Translation API
- VS Code

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Create and activate the virtual environment.
4. Install the required library:

    python -m pip install deep-translator

5. Run the following command:

    python main.py

6. Enter your text.
7. Select the source and target languages.
8. Click **Translate →** to get the translated result.
